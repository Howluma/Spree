# SpreeCore 1.8.25 — Legendary Tooltip Cleanup

**Target:** Paper 1.21.11  
**Distributables:** `SpreeCore-1.8.25.jar` and `SpreeCore-Resource-Pack-1.8.25.zip`

## Fixes
- **Enchantments remain functional but their names/levels are hidden** in all seven legendary tooltips. v1.8.24 accidentally removed `HIDE_ENCHANTS`; this restores that item flag.
- No enchantment glint (false glint override).
- Removes a redundant `minecraft:item_name` component **when present**, keeping the readable, bold custom display name as the tooltip title.
- **Netherite-equivalent attack damage and speed stay visible**, along with ability lore and killstreak unlock rules.
- Detects and repairs older item metadata on join/inventory refresh, avoiding continuous rewrites on unenchanted legendaries.
- All other legendary abilities and SpreeCore systems unchanged. The resource-pack artwork and Pantheon-style tooltip frames are **byte-identical** to v1.8.24.

**Advanced tooltip caveat:** If a player enables Minecraft's F3+H tooltips, vanilla can display the item registry ID and numeric component count. Those are generated by the client and cannot be selectively hidden with ordinary Paper item metadata. Players can toggle F3+H off.

## Verification
Java 21 compilation and mock regression tests passed for seven legendary types, enchantment preservation/visibility, name cleanup, no-glint, mainhand combat statistics, item durability, and idempotence; Blood Butcher ability gating/health tests passed. Class verification passed for **107/107** class files. Live Paper multiplayer testing remains outstanding.

## Installation
